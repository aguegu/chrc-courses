TX6AX-BLE 函数介绍
===

`tx6ax-ble` 与 `tx6ax`、`tx6a4d` 是**同一块硬件**、同一套按键与旋钮，区别在**无线链路**：它把遥控器变成一个标准的**蓝牙（Bluetooth LE）HID 游戏手柄**。`rx4mx-ble` 接收机像连普通蓝牙手柄一样连它；手机、电脑也能把它当成手柄。

**配对**：遥控器开机后自动广播，由主机（接收机）发起配对并绑定。接收机那边单击 boot 键打开 30 秒配对窗口即可。遥控器的 LED 在连上并加密后常亮。长按遥控器的 PAIR 键（boot 键）3 秒，清除绑定。

`输入`量与 `tx6ax` 相同：**Button（按键）** 和 **Stick（旋钮）**。

**Button（按键）** 只有 `true`（按下）和 `false`（未按下）两种状态，用 `getButton(index)` 读取，index 取值 `[0, 1, 2, 3]`：

| index | 按键 |
| - | - |
| `0` | L：左侧外按键（及左摇杆按下） |
| `1` | L2：左侧内按键 |
| `2` | R2：右侧内按键 |
| `3` | R：右侧外按键（及右摇杆按下） |

**Stick（旋钮）** 用 `getStick(index)` 读取**原始的无符号读数** `[0, 255]`（约 `128` 为中点），index 取值 `[0, 1, 2, 3, 4, 5]`：右摇杆 X、右摇杆 Y、左摇杆 Y、左摇杆 X、左旋钮、右旋钮。摇杆推向**左 / 上**时读数变大。

**输出：报文（Report）**

`tx6ax` 发的是 16 个通道；`tx6ax-ble` 发的是**游戏手柄的 HID 报文**，共 10 个字节，格式与 ShanWan Q34P 手柄完全相同。用 `setReport(index, value)` 设置其中一个字节，`getReport(index)` 读回。`app.h` 给每个字节和按键位都起了名字：

| 字节 | 含义 | 取值 |
| - | - | - |
| `REPORT_X` / `REPORT_Y` | 左摇杆 水平 / 垂直 | `0` 左 / 上 .. `255` 右 / 下 |
| `REPORT_Z` / `REPORT_RZ` | 右摇杆 水平 / 垂直 | 同上 |
| `REPORT_HAT` | 十字键（方向键） | `0` 上 .. `7` 左上，`HAT_REST` 为松开 |
| `REPORT_BUTTONS1` | 按键 1-8 | 按位：`BTN1_A`、`BTN1_B`、`BTN1_X`、`BTN1_Y`、`BTN1_LB`、`BTN1_RB` |
| `REPORT_BUTTONS2` | 按键 9-16 | 按位：`BTN2_LT`、`BTN2_RT`、`BTN2_VIEW`、`BTN2_MENU`、`BTN2_L3`、`BTN2_R3` |
| `REPORT_RT` / `REPORT_LT` | 右 / 左扳机 | `0` 松开 .. `255` 按到底 |

> 注意方向：HID 规定摇杆 `0` 端是**左 / 上**，而这块遥控器的摇杆推向左 / 上时读数是 `255`，所以发送前要“翻转”一下：`255 - getStick(...)`。

**默认程序**（见 `src/app.c`）按普通手柄的布局发送：

| 输入 | 报文 |
| - | - |
| 左摇杆 X / Y（`getStick(3)` / `(2)`） | `REPORT_X` / `REPORT_Y`（翻转） |
| 右摇杆 X / Y（`getStick(0)` / `(1)`） | `REPORT_Z` / `REPORT_RZ`（翻转） |
| 左旋钮（`getStick(4)`） | `REPORT_LT`（常用作限速） |
| 右旋钮（`getStick(5)`） | `REPORT_RT`（常用作微调） |
| 按键 0 / 1 / 2 / 3 | `BTN1_LB` / `BTN2_VIEW` / `BTN2_MENU` / `BTN1_RB` |
| 十字键 | `HAT_REST`（本遥控器没有十字键） |

另外，每个旋钮的位置被分成 4 档（`>> 6`，即 `0..3`），用 2 个按键位发出：左旋钮的高位 / 低位在按键 9 / 13，右旋钮的在按键 10 / 16。接收机可以直接把它当作“档位开关”来用；需要更细的档位，就读 `REPORT_LT` / `REPORT_RT` 的原始值自己划分。

> 旋钮与手柄扳机的区别：手柄的 LT / RT 松手会弹回 `0`；旋钮则停在拧到的位置。

“重复计算”发生在 `loop()` 中：系统每 20ms（`50Hz`）调用一次，然后把报文原样发出，**不管有没有变化**。`loop()` 里没有设置的字节保持上一次的值。

**失联提醒**：与接收机的链路断开时（如接收机关机、超出距离），系统调用 `onDisconnect()`；默认程序让蜂鸣器响起（`setBuzzer(true)`），重新连上后自动停止。
