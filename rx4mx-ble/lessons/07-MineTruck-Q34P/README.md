RX4MX-BLE 矿卡：ShanWan Q34P 版（MineTruck-Q34P）
===

本课从 `06-Combo-Q34P` 分出，做一台**矿卡**（mine truck）：由 ShanWan Q34P（D 模式，蓝牙 LE）直接遥控，不需要 `tx6ax-ble`，控制逻辑全在接收机。矿卡用一个舵机转向，用到四路电机输出：后轮、前轮、翻斗，以及一组可选的灯。

为什么不直接用 `03-Combo`：那一课的限速和方向微调来自 `tx6ax-ble` 的两个**旋钮**（`REPORT_LT`、`REPORT_RT`），旋钮拧到哪里就停在哪里；而 Q34P 的 LT、RT 是**扳机**，松手就弹回 `0`。所以本课把 RT 直接当油门，微调改用 View / Menu 两个按键。

## 映射表

| 手柄 | 输出 | 作用 |
|---|---|---|
| 左摇杆横轴（`REPORT_X`） | 舵机 SM0 | 转向，**反向**（适配舵机连杆）；幅度为摇杆全行程的 `STEER_RATIO`%（`50`：约 1.25～1.75 ms） |
| RT 扳机（`REPORT_RT`） | 电机 0（后轮）、电机 1（前轮） | 油门，前后轮同值（四驱）：`RT × 120 / 255 × 挡位比例`，最大 `120`（`DRIVE_MAX`） |
| LB | 电机 0、1 | **方向开关**：每按一次在前进 / 倒车之间切换，不用按住；上电为前进 |
| RB（按住） | 电机 0、1 | **刹车**（`-128`，短接刹车），优先于油门 |
| Y / A | 电机 0、1 | **变速箱**：升 / 降一挡，四挡为油门的 12% / 25% / 50% / 100%；上电在 1 挡 |
| 右摇杆纵轴（`REPORT_RZ`） | 电机 2（翻斗） | 推上举升、拉下放下，最大 `120`；有小死区，不受挡位影响 |
| X | 电机 3（灯，可选） | 模式循环：**灭 → 亮 → 闪烁**；亮度 `LED_BRIGHTNESS`（`64`） |
| View / Menu | 舵机 SM0 | 转向**微调**：中位每按一次左 / 右移 0.01 ms，最多 ±0.4 ms |
| （连接断开） | 全部 | 电机 0、1、2 **停转**，舵机回到微调后的中位，灯**快闪**；手柄一重新连上（`onPaired()`），快闪就停 |

电机 3 上可接一组 LED（接在正向）：值为正时亮，为 `0` 时灭。

## 按键的“按下沿”

LB、Y / A、X、View / Menu 都只在按键**刚按下**的那一次报文里生效（本次按下、上次未按），一直按住也只算一次：

```
pressed = buttons & ~buttonsLast;   // 这次新按下的键
buttonsLast = buttons;
```

## 转向

`舵机 = 150 - (主方向 × 2/5 × STEER_RATIO / 100 + 微调)`（代码里写成 `steer * 2 * STEER_RATIO / 500`，先乘后除，整数运算不丢精度）。主方向取自 `centered()`（见 `00-Default`），HID 横轴 `0` 端在左；前面的减号让方向反过来。微调不受 `STEER_RATIO` 影响，与摇杆同向：按 View 等于把摇杆往左轻推一点。

## 油门、方向与刹车

```
油门 = RT × DRIVE_MAX / 255       // 0..120，电机驱动保护
油门 = 油门 × gears[gear] / 100   // 按挡位缩放：12/25/50/100%
RB 按住       → 刹车（-128）
LB 切到倒车   → -油门
否则          → 油门
电机 0 = 电机 1 = 上面的结果      // 前后轮同值
```

`120` 是 `setMotor()` 最大值 `127` 的 240/255（约 94%），用来**保护电机驱动**：前进、倒车、翻斗都不会超过它。挡位和方向在断线后保持不变。

## 翻斗

```
电机 2 = -centered(右摇杆纵轴, DUMPER_DEADZONE) × DRIVE_MAX / 127   // -120..120
```

HID 纵轴 `0` 端在上，所以取负：推上为正，举升。摇杆中位附近的小死区（`DUMPER_DEADZONE`）让放手时翻斗不会慢慢动。

## 灯与 `tick()`

闪烁需要一个稳定的时钟，`loop()` 做不到：Q34P 只在手柄有变化时才发报文（实测：操作时每秒约 40～63 份，**静止时为 0**），静止时 `loop()` 根本不运行。所以脚手架每秒调用 32 次 `tick()`（每 31.25 ms 一次），**不管有没有报文**。32 次正好是 1 秒，算时间很方便：16 次 = 0.5 秒，8 次 = 250 ms，4 次 = 125 ms。

```
void tick() {
  static uint8_t ticks;
  ++ticks;
  if (ticks % 8 == 0)   // 每 250 ms：正常闪烁，2 Hz
    blinkLit = !blinkLit;
  if (ticks % 4 == 0)   // 每 125 ms：断线时的快闪，快一倍
    lostLit = !lostLit;
  ledsShow();
}
```

`ledsShow()` 按当前状态设置电机 3：断线时用 `lostLit`，否则按 X 选的模式（灭、亮，或用 `blinkLit` 闪烁）。

## 断线保护（`onDisconnect()`）

手柄关机或超出距离、连接断开时：电机 0、1、2 设为 `0` **停转**（不刹车）；舵机 SM0 回到**加上微调后的中位**（`150 - 微调`），车轮回正；灯改为**快闪**，不管 X 选的是什么模式，提示连接已断开。手柄一重新连上，脚手架就调用 `onPaired()`（在任何报文之前），快闪立刻停止，灯回到 X 选的模式；之后手柄一有操作，`loop()` 接管，恢复控制。只靠 `loop()` 不够：Q34P 开机后如果没人动它，就不发报文，`loop()` 不运行，灯会一直快闪。

注意：连接要在“监督超时”之后才算断开，Q34P 设的是 2 秒，所以手柄失联后，小车最多还会按最后的指令行驶约 2 秒。和 `01-OnDisconnect` 一样，**每个会让车动起来的程序都应该写 `onDisconnect()`**——脚手架本身不会替你停车。

## 装车提示

  * 如果某个电机转向反了，可以在代码里给它的值取负，或者把这个电机的两根线对调。
  * Q34P 需切到 **D** 档（蓝牙 LE 的 HID 手柄，名称 `GamepadSpace-Q34P`）。第一次使用用配对键开机，接收机会配对并记住它。
