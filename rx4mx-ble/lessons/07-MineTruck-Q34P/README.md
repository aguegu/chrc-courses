RX4MX-BLE 矿卡：ShanWan Q34P 版（MineTruck-Q34P）
===

本课从 `06-Combo-Q34P` 分出，做一台**矿卡**（mine truck）：同样由 ShanWan Q34P（D 模式，蓝牙 LE）直接遥控，不需要 `tx6ax-ble`，控制逻辑全在接收机。矿卡用到四路电机输出：

  * 电机 0（DM0）= **后轮**驱动
  * 电机 1（DM1）= **前轮**驱动——与后轮一起受油门、倒挡、刹车控制（四驱）
  * 电机 2（DM2）= **翻斗升降**，由右摇杆纵轴单独控制
  * 电机 3（DM3）= **灯**（可选）：可接两组反向并联的 LED，值为正时一组亮、为负时另一组亮、为 0 时都不亮；由 X 键逐档切换

转向仍是舵机 SM0。变速箱、微调和断线保护沿用 `06-Combo-Q34P`。

为什么不直接用 `03-Combo`：那一课的限速和方向微调来自 `tx6ax-ble` 的两个**旋钮**（`REPORT_LT`、`REPORT_RT`），旋钮拧到哪里就停在哪里；而 Q34P 的 LT、RT 是**扳机**，松手就弹回 `0`——限速会一直是 0，小车不动。所以本课把 RT 直接当油门，微调改用 View / Menu 两个按键。

**操作**：

  * 左摇杆横轴（`REPORT_X`）= 方向 → 舵机 SM0（**反向**，适配舵机连杆的安装方向）。中位 1.5 ms；转向幅度由 `STEER_RATIO` 设定，是摇杆全行程的百分比：`50` 时左满约 1.75 ms、右满约 1.25 ms，`100` 时为 2.0 ms 到 1.0 ms。
  * RT 扳机（`REPORT_RT`，`0..255`）= 油门 → 电机 0 和电机 1（前后轮同值）：`RT × 120 / 255`，再乘挡位比例。松开停止，4 挡扣到底为 `120`（`DRIVE_MAX`）。`120` 是 `setMotor()` 最大值 `127` 的 240/255（约 94%），用来**保护电机驱动**：前进、倒车都不会超过它。
  * Y / A（`BTN1_Y`、`BTN1_A`）= **变速箱**：每按一次升 / 降一挡，共四挡，分别是油门的 12%、25%、50%、100%（`gears[]`，前进、倒车都按此比例）。上电时在 1 挡（12%），最高 4 挡、最低 1 挡；断线后挡位保持不变。
  * 按住 LB（`BTN1_LB`）= **倒挡**：此时 RT 让电机 0、1 反转。
  * 按住 RB（`BTN1_RB`）= **刹车**（电机 0、1 设为 `-128`，短接刹车），优先于油门。
  * 右摇杆纵轴（`REPORT_RZ`）= **翻斗** → 电机 2：推上举升，拉下放下。HID 纵轴 `0` 端在上，所以取负（`-centered()`）。摇杆中位附近有小死区（`DUMPER_DEADZONE`），放手时翻斗不会慢慢动；最大同样是 `120`（`DRIVE_MAX`），不受挡位影响。
  * X 键（`BTN1_X`）= 灯（电机 3）：每按一次切到下一档，依次为 `0`（灭）、`64`（正向那组亮）、`0`（灭）、`-64`（反向那组亮），然后回到开头循环（`xSteps[]`）。`64` 约为半占空比，灯会比满值暗一些；想更亮可以改大（不超过 `120`）。上电时为 `0`（灭）。和换挡一样只认**按下沿**，按住不放只算一次。
  * View / Menu（`BTN2_VIEW`、`BTN2_MENU`）= 方向**微调（trim）**：每按一次，舵机中位向左 / 向右移一步（0.01 ms），最多 ±0.4 ms，保持到重新上电。

**断线保护（`onDisconnect()`）**：手柄关机或超出距离、连接断开时，电机 0、1 **刹车**（`-128`）；电机 2 也**刹车**，让举起的翻斗停在原处，不会被货物压下来；灯（电机 3）设为刹车，两端短接、两组都**熄灭**，档位**归零**——手柄重新连上后灯保持熄灭，直到再按 X；舵机 SM0 回到**加上微调后的中位**（`150 - 微调`），车轮回正。手柄重新连上、发来下一份报文后，`loop()` 接管，恢复控制。注意：连接要在“监督超时”之后才算断开，Q34P 设的是 2 秒，所以手柄失联后，小车最多还会按最后的指令行驶约 2 秒。和 `01-OnDisconnect` 一样，**每个会让车动起来的程序都应该写 `onDisconnect()`**——脚手架本身不会替你停车。

**按键的“按下沿”**：微调、换挡和 X 键只在按键**刚按下**的那一次报文里生效（本次按下、上次未按），一直按住也只算一步：

```
pressed = buttons2 & ~buttons2Last;   // 这次新按下的键
buttons2Last = buttons2;
```

**转向**：`舵机 = 150 - (主方向 × 2/5 × STEER_RATIO / 100 + 微调)`（代码里写成 `steer * 2 * STEER_RATIO / 500`，先乘后除，整数运算不丢精度）。微调不受 `STEER_RATIO` 影响，每按一次始终是 0.01 ms。主方向取自 `centered()`（见 `00-Default`），HID 横轴 `0` 端在左；前面的减号让方向反过来。微调与摇杆同向：按 View 等于把摇杆往左轻推一点。

**油门与倒挡**：

```
油门 = RT × DRIVE_MAX / 255       // 0..120，电机驱动保护
油门 = 油门 × gears[gear] / 100   // 按挡位缩放：12/25/50/100%
RB 按住  → 刹车（-128）
LB 按住  → -油门（倒车）
否则     → 油门（前进）
电机 0 = 电机 1 = 上面的结果     // 前后轮同值
```

**翻斗**：

```
电机 2 = -centered(右摇杆纵轴, DUMPER_DEADZONE) × DRIVE_MAX / 127   // -120..120
```

如果装车后某个电机转向反了，可以在代码里给它的值取负，或者把这个电机的两根线对调。

Q34P 需切到 **D** 档（蓝牙 LE 的 HID 手柄，名称 `GamepadSpace-Q34P`）。第一次使用用配对键开机，接收机会配对并记住它。
