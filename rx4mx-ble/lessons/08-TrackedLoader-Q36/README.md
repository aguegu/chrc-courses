RX4MX-BLE 履带装载机：ShanWan Q36 版（TrackedLoader-Q36）
===

本课做一台**履带装载机**，直接由 ShanWan Q36 迷你手柄遥控（D 模式，蓝牙 LE，名称 `Q36 for Android`），不需要 `tx6ax-ble`。控制逻辑全在接收机。

第一步从 `02-MiniTank` 分出来：先让履带跑起来，装载机的大臂和铲斗下一步再加。

为什么不直接用 `02-MiniTank`：那一课要用两根**摇杆**（坦克模式一根摇杆管一条履带）和两个**旋钮**（`REPORT_RT` 选模式、`REPORT_LT` 限速）。Q36 是迷你手柄，**没有摇杆**，只有十字键；L2、R2 也只是按键（报文里只会是 `0` 或 `255`），没有可以停在中间的模拟量。所以本课只保留 arcade 驾驶，用**十字键**开车，速度固定。

**操作**：

  * 十字键 = 驾驶 → 电机 0（左履带）、电机 1（右履带）：
    * 上 / 下：前进 / 后退；
    * 左 / 右：原地转向（两条履带反向）；
    * 斜方向：边走边转；
    * 松开：停车。
  * 十字键是“全有或全无”：按下就是满杆，所以速度由 `DRIVE_SPEED` 设定（`setMotor()` 最大值 `127` 中的 `100`）。

**断线保护（`onDisconnect()`）**：手柄关机或超出距离、连接断开时，两条履带**停转**。手柄重新连上、发来下一份报文后，`loop()` 接管。和 `01-OnDisconnect` 一样，**每个会让车动起来的程序都应该写 `onDisconnect()`**。

**十字键当摇杆**（`dpad()`）：Q36 的十字键平时报告在“方向键”（`REPORT_HAT`）里：`0` 上、`1` 右上、`2` 右……`7` 左上，松开时大于 `7`。用两张表把 8 个方向换成“油门”和“转向”，每个只取 `-127`、`0` 或 `127`：

```
方向     0  1  2  3  4  5  6  7
油门     +  +  0  -  -  -  0  +
转向     0  +  +  +  0  -  -  -
```

Q36 还有一个**摇杆模式**（同时按 View（−）和 Home 切换）：十字键改为报告左摇杆的 X、Y，而且只有三个值（`0`、`0x80`、`0xFF`）。`dpad()` 在方向键松开时读 X、Y，所以两种模式都能开车。注意：单独按 Home 会进入**多媒体模式**（指示灯变黄），这时手柄不再发游戏报文，车不会动，再按一次 Home 退出。

**arcade 混控**（原理同 `02-MiniTank`）：

```
左履带 = 油门 + 转向
右履带 = 油门 - 转向
```

斜方向时两者相加会超过 `127`，所以按较大的一侧缩放，保持比例；右履带取负号，适配镜像安装的电机（同 `02-MiniTank`）。

第一次使用用配对键开机，接收机会配对并记住它；之后用 Home 键开机，手柄保持原来的地址，接收机会自动重连。
