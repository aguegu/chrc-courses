RX4MX-BLE 双摇杆小车（Combo）
===

本课把一台 RC 小车的**油门与转向分给两根摇杆**：左摇杆纵轴给油门、右摇杆横轴打方向——这也是遥控车最常见的手法。控制逻辑全在接收机，`tx6ax-ble` 只负责发原始摇杆值。它也是 `04-forklift` 的行驶基础。

**操作**（摇杆经 `centered()` 还原为带符号值，见 `00-Default`）：

  * 左摇杆纵轴（`REPORT_Y`）= 油门 → 电机 0，受左旋钮（`REPORT_LT`）限速。推上为前进（`-centered()`，HID 的 `0` 端在上）。
  * 右摇杆横轴（`REPORT_Z`）= 方向 → 舵机 SM0；右旋钮（`REPORT_RT`）做方向**微调（trim）**。
  * 按键 0（L，报文里的 `BTN1_LB`）= 刹车（电机设为 `-128`，短接刹车）。

**转向混合**：`steer = 主方向 × 3/4 + 微调 × 1/4`，再映射成舵机脉宽（`150 + steer × 2/5`，即中位 150 附近摆动）。HID 横轴 `0` 端在左，与 `tx6ax` 相反，所以这里的主方向不再取负。

**限速**：油门 = `摇杆 × speed / 255`，`speed` 取自左旋钮（`0..255`）——旋钮拧到底为满速，拧到 0 则不动，相当于一个总速度上限。
