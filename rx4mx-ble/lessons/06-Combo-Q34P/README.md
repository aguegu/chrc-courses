RX4MX-BLE 双摇杆小车：ShanWan Q34P 版（Combo-Q34P）
===

本课是 `03-Combo` 的 **ShanWan Q34P 手柄版**：一台舵机转向、单电机驱动的 RC 小车，直接由 Q34P（D 模式，蓝牙 LE）遥控，不需要 `tx6ax-ble`。控制逻辑全在接收机。

为什么不直接用 `03-Combo`：那一课的限速和方向微调来自 `tx6ax-ble` 的两个**旋钮**（`REPORT_LT`、`REPORT_RT`），旋钮拧到哪里就停在哪里；而 Q34P 的 LT、RT 是**扳机**，松手就弹回 `0`——限速会一直是 0，小车不动。所以本课把 RT 直接当油门，微调改用 View / Menu 两个按键。

**操作**：

  * 左摇杆横轴（`REPORT_X`）= 方向 → 舵机 SM0（**反向**，适配舵机连杆的安装方向）。中位 1.5 ms；转向幅度由 `STEER_RATIO` 设定，是摇杆全行程的百分比：`50` 时左满约 1.75 ms、右满约 1.25 ms，`100` 时为 2.0 ms 到 1.0 ms。
  * RT 扳机（`REPORT_RT`，`0..255`）= 油门 → 电机 0：`RT × 120 / 255`，再乘挡位比例。松开停止，4 挡扣到底为 `120`（`DRIVE_MAX`）。`120` 是 `setMotor()` 最大值 `127` 的 240/255（约 94%），用来**保护电机驱动**：前进、倒车都不会超过它。
  * Y / A（`BTN1_Y`、`BTN1_A`）= **变速箱**：每按一次升 / 降一挡，共四挡，分别是油门的 25%、50%、75%、100%（`gears[]`，前进、倒车都按此比例）。上电时在 1 挡（25%），最高 4 挡、最低 1 挡；断线后挡位保持不变。
  * 按住 LB（`BTN1_LB`）= **倒挡**：此时 RT 让电机 0 反转。
  * 按住 RB（`BTN1_RB`）= **刹车**（电机设为 `-128`，短接刹车），优先于油门。
  * View / Menu（`BTN2_VIEW`、`BTN2_MENU`）= 方向**微调（trim）**：每按一次，舵机中位向左 / 向右移一步（0.01 ms），最多 ±0.4 ms，保持到重新上电。

**断线保护（`onDisconnect()`）**：手柄关机或超出距离、连接断开时，电机 0 **刹车**（`-128`），舵机 SM0 回到**加上微调后的中位**（`150 - 微调`），车轮回正。手柄重新连上、发来下一份报文后，`loop()` 接管，恢复控制。注意：连接要在“监督超时”之后才算断开，Q34P 设的是 2 秒，所以手柄失联后，小车最多还会按最后的指令行驶约 2 秒。和 `01-OnDisconnect` 一样，**每个会让车动起来的程序都应该写 `onDisconnect()`**——脚手架本身不会替你停车。

**按键的“按下沿”**：微调和换挡只在按键**刚按下**的那一次报文里生效（本次按下、上次未按），一直按住也只算一步：

```
pressed = buttons2 & ~buttons2Last;   // 这次新按下的键
buttons2Last = buttons2;
```

**转向**：`舵机 = 150 - (主方向 × 2/5 × STEER_RATIO / 100 + 微调)`（代码里写成 `steer * 2 * STEER_RATIO / 500`，先乘后除，整数运算不丢精度）。微调不受 `STEER_RATIO` 影响，每按一次始终是 0.01 ms。主方向取自 `centered()`（见 `00-Default`），HID 横轴 `0` 端在左；前面的减号让方向反过来。微调与摇杆同向：按 View 等于把摇杆往左轻推一点。

**油门与倒挡**：

```
油门 = RT × DRIVE_MAX / 255       // 0..120，电机驱动保护
油门 = 油门 × gears[gear] / 100   // 按挡位缩放：25/50/75/100%
RB 按住  → 刹车（-128）
LB 按住  → -油门（倒车）
否则     → 油门（前进）
```

Q34P 需切到 **D** 档（蓝牙 LE 的 HID 手柄，名称 `GamepadSpace-Q34P`）。第一次使用用配对键开机，接收机会配对并记住它。
