RX4MX-BLE 双摇杆小车：ShanWan Q34P 版（Combo-Q34P）
===

本课是 `03-Combo` 的 **ShanWan Q34P 手柄版**：一台舵机转向、单电机驱动的 RC 小车，直接由 Q34P（D 模式，蓝牙 LE）遥控，不需要 `tx6ax-ble`。控制逻辑全在接收机。

为什么不直接用 `03-Combo`：那一课的限速和方向微调来自 `tx6ax-ble` 的两个**旋钮**（`REPORT_LT`、`REPORT_RT`），旋钮拧到哪里就停在哪里；而 Q34P 的 LT、RT 是**扳机**，松手就弹回 `0`——限速会一直是 0，小车不动。所以本课把 RT 直接当油门，微调改用 View / Menu 两个按键。

**操作**：

  * 左摇杆横轴（`REPORT_X`）= 方向 → 舵机 SM0。中位 1.5 ms，左满约 2.0 ms、右满约 1.0 ms（**反向**，适配舵机连杆的安装方向）。
  * RT 扳机（`REPORT_RT`，`0..255`）= 油门 → 电机 0：松开停止，扣到底全速前进（`0..127`）。
  * 按住 LB（`BTN1_LB`）= **倒挡**：此时 RT 让电机 0 反转。
  * 按住 RB（`BTN1_RB`）= **刹车**（电机设为 `-128`，短接刹车），优先于油门。
  * View / Menu（`BTN2_VIEW`、`BTN2_MENU`）= 方向**微调（trim）**：每按一次，舵机中位向左 / 向右移一步（0.01 ms），最多 ±0.4 ms，保持到重新上电。

**按键的“按下沿”**：微调只在按键**刚按下**的那一次报文里生效（本次按下、上次未按），一直按住也只算一步：

```
pressed = buttons2 & ~buttons2Last;   // 这次新按下的键
buttons2Last = buttons2;
```

**转向**：`舵机 = 150 - (主方向 × 2/5 + 微调)`。主方向取自 `centered()`（见 `00-Default`），HID 横轴 `0` 端在左；前面的减号让方向反过来。微调与摇杆同向：按 View 等于把摇杆往左轻推一点。

**油门与倒挡**：

```
油门 = RT / 2              // 0..127
RB 按住  → 刹车（-128）
LB 按住  → -油门（倒车）
否则     → 油门（前进）
```

Q34P 需切到 **D** 档（蓝牙 LE 的 HID 手柄，名称 `GamepadSpace-Q34P`）。第一次使用用配对键开机，接收机会配对并记住它。
