RX4MX-BLE 叉车（Forklift）演示
===

在 `rx4mx-ble` 上驾驶一台**叉车**：既能像小车一样行驶，又能操作举升臂。控制逻辑全部在接收机上，`tx6ax-ble` 只负责发原始摇杆值。

本课在 `03-Combo`（双摇杆小车：油门 + 转向）的基础上扩展，加入俯仰与举升。摇杆经 `centered()`（见 `00-Default`）还原为带符号值再运算；HID 摇杆 `0` 端是左 / 上，符号与 `rx4mx` 的课程相反，车辆动作相同。

**操作**：

  * 左摇杆纵轴（`REPORT_Y`）= 前进 / 后退（电机 0），受左旋钮（`REPORT_LT`）限速；按键 1（L2，报文里的 `BTN2_VIEW`）= 行驶刹车。
  * 左摇杆横轴（`REPORT_X`）= 举升臂俯仰（电机 2）。
  * 右摇杆纵轴（`REPORT_RZ`）= 举升（电机 1）；按键 2（R2，报文里的 `BTN2_MENU`）= 举升刹车。
  * 右摇杆横轴（`REPORT_Z`）+ 右旋钮（`REPORT_RT`，微调）= 转向舵机 SM0。

**手感**：油门 / 举升 / 俯仰用 `stickToMotor()` 做了**平方响应**——中点附近更细腻，满杆才到全速；举升与俯仰再额外 `/4` 降速，便于精细操作。刹车按键把对应电机设为 `-128`（短接刹车）。
