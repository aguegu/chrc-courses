RX4MX 叉车灯效演示
===

本课在 `rx4mx`（音频 + 灯带全开：`AUDIO_ON_SM1_SM2 1`、`NEO_ON_SM3 1`）上，把一辆车的**灯光系统**做成随操作联动的效果，并配上音效。SM1+SM2 接音频模块、SM3 接 16 颗 NeoPixel 灯环、SM0 为舵机、外加 4 路电机。

因为 `tx6ax` 送来的是原始无符号读数，这里用 `centered()`（见 `00-Default`）把摇杆还原成带符号的 `-127..127`（4 个电机摇杆通道 0–3 设了死区 8，转向通道不设死区），于是可以用“正 / 负 / 零”来判断操作方向。

**输入 → 灯光映射**（见 `loop()`）：

  * 通道 1（油门）：为负亮**前照灯**，为正亮**倒车灯**；当油门值大于当前电机输出（`getMotor(1)`）时亮**刹车灯**。
  * 通道 4（转向）：为正亮**左转向灯**，为负亮**右转向灯**（随 `step` 闪烁）。
  * 通道 0 或 2 有输入时，点亮**顶灯 / 警示灯**（橙色交替闪烁）。

**灯环分区**（16 颗 LED 的编号，见文件末尾的数组）：前照灯 `0-3`、左转 `4,11`、右转 `7,8`、刹车 `12,15`、倒车 `13,14`、顶灯 `5,6,9,10`。

**音效**：打转向灯播放 `0003.mp3`，开顶灯播放 `0002.mp3`，按键 0（通道 6）播放 `0001.mp3`。灯带 / 音频 API 的详细说明见 `10-NeoDemo` 与 `20-AudioDemo`。
