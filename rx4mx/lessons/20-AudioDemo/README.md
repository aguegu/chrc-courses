RX4MX 音频（MP3）演示
===

本课在 `rx4mx` 上驱动 **MY1690 MP3 音频模块**。把 `app.h` 顶部的开关设为 `AUDIO_ON_SM1_SM2 1`，SM1+SM2 两个排针即从“舵机”切换为“音频模块”接口（UART + BUSY）；此时电机仍为 4 路，舵机剩 SM0、SM3 两路。

> 音频文件需预先放到模块的 SD 卡 / Flash 中，并以数字编号命名（如 `0002.mp3`、`0005.mp3`）。`mpPlay` 传入的就是这个编号。

**音频相关函数**

`onPlayerReady()`：音频模块上电自检完成后（约 1 秒）自动调用一次。通常在这里设置初始音量、播放开机提示音。本例用它设置音量。

`mpVolume(value)`：设置音量，`0–30`（模块共 31 档，含静音）。

`mpPlay(filesn, force)`：播放编号为 `filesn` 的音频。

  * `force = true`：即使正在播放同一个文件，也重新从头触发——适合“每次按下都重播”的音效。
  * `force = false`：仅在模块空闲（BUSY 为低）时才开始播放——适合循环的背景音。
  * 无论 `force` 与否，内部限流为每 80ms 最多触发一次。

`mpStop()`：立即停止当前播放。

`mpLoop(isLoop)`：设置是否循环播放当前文件。

**本例效果**（见 `src/app.c`）：

  * 开机后 `onPlayerReady()` 把音量设为 `15`。
  * 按键 3（通道 9）为“音频总开关”，每按一次切换开 / 关；关闭时调用 `mpStop()`。
  * 开启状态下：按键 0 / 1 / 2（通道 6 / 7 / 8）分别触发 `0002 / 0003 / 0004.mp3` 的一次性音效（`force = true`），同时以 `mpPlay(5, false)` 循环播放 `0005.mp3` 作为背景音。
  * 电机经 `centered()`（死区 10）驱动；SM0、SM3 两路舵机由旋钮（通道 4、5）控制。

> 在 `tx6ax` 上，4 个按键位于通道 6–9，摇杆 / 旋钮位于通道 0–5。
