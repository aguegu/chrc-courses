RX4MX 失联保护（onDisconnect）
===

本课演示**失联保护**。接收机与遥控器断开后（约 400ms 收不到有效数据包），系统会自动调用一次 `onDisconnect()`，让你把车辆置于安全状态。

`loop()` 与 `00-Default` 相同：4 路摇杆经 `centered()`（死区 8，见 `00-Default`）驱动电机，两个旋钮（通道 4、5）各驱动一对镜像舵机。

新增的回调 **`onDisconnect()`**：把 4 个电机全部停转（`setMotor(i, 0)`），并让所有舵机回到中位（`setServo(i, 150)` = 1.5ms）。

> 该回调只在链路真正断开后触发一次；若在超时窗口内又收到有效数据包，则不会触发——短暂的射频抖动不会误报。遥控车辆务必实现失联保护，避免失控暴走。
