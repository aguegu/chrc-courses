RX4MX 叉车 + 灯光音效（Forklift+）
===

本课在 `04-forklift`（纯机械叉车）的基础上，打开音频 + 灯带（`app.h` 两个开关都设为 `1`），加上一整套**车灯**与**引擎声**。

**驾驶操作与 `04-forklift` 完全相同**（drive / 转向 / 俯仰 / 举升、限速与刹车），详见那一课。这里根据行驶状态点亮 16 颗灯环上的各组灯：

  * **前照灯**（白，LED 0–3）：按键 3（通道 9）开 / 关。
  * **倒车灯**（白，LED 13、14）：挂倒挡时亮。
  * **刹车灯**（红，LED 12、15）：踩行驶刹车（按键 1）或倒车时亮。
  * **转向灯**（黄闪，左 4/11、右 7/8）：打方向时按方向闪烁。
  * **顶灯 / 警示灯**（橙闪，LED 5、6、9、10）：操作举升臂时闪烁。

**引擎声**：`0005.mp3` 在音频模块（SM1+SM2）上循环播放，音量在 `onPlayerReady()` 中设置。

也就是说：`04-forklift` 教“怎么开”，本课教“怎么在能开的车上把灯光、音效做全”。灯带 / 音频 API 的详细说明见 `10-NeoDemo` 与 `20-AudioDemo`。
