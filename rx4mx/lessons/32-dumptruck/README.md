RX4MX 自卸车 / 翻斗车（Dump Truck）演示
===

本课基于 `31-forklift`，同样是音频 + 灯带全开的整车演示，只是把叉车的**举升臂换成了一个会翻斗的车斗**。

**摇杆操作**（经 `centered()` 还原为带符号值，见 `00-Default`）：

  * 右摇杆纵轴（通道 1）= 前进 / 后退（电机 0），受左旋钮（通道 4）限速。
  * 右摇杆横轴（通道 0）+ 右旋钮（通道 5，微调）= 转向舵机 SM0。
  * 左摇杆横轴（通道 3）= **车斗升 / 降**（电机 1）。

**按键**（`tx6ax` 上按键位于通道 6–9）：

  * 按键 0 = **车灯开 / 关**（按一下切换）。
  * 按键 2 = **声音开 / 关**（按一下切换）。
  * 按键 3 = **刹车**（按住时电机置 `-128` 刹停）。

**车灯**（**12 颗** LED，采用 `04-Crawler` 的分层亮度风格）：开大灯时各灯先亮起一层暗淡的“示廓光”，事件发生时再叠加高亮。分组：前照灯 `0/1/4/5`、左转 `2/9` 与右转 `3/8`（打方向黄闪）、倒车灯 `6/11`（倒车时白）、刹车灯 `7/10`（红）。

**音效**（可用按键 2 开 / 关；音量在 `onPlayerReady()` 中设置）：引擎声 `0005.mp3` 循环打底；打方向播放 `0003.mp3`；翻斗时播放 `0002.mp3`。

> 与叉车的区别只在“干活”的部分：叉车是俯仰 + 举升两路（`31-forklift`），自卸车只有升降车斗一路。
