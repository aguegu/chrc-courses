RX4MX 挖掘机（Excavator）演示
===

在 `rx4mx`（默认配置：4 电机 + 4 舵机）上开一台**挖掘机**：4 路机械臂用电机，履带与附件用舵机。控制逻辑全在接收机，`tx6ax` 只发原始摇杆 / 按键值。

**摇杆 / 旋钮**（经 `centered()` 还原为带符号值，见 `00-Default`；机械臂死区 `0x20`）：

  * 右摇杆 X（通道 0）= **铲斗** → 电机 0
  * 右摇杆 Y（通道 1）= **大臂** → 电机 1
  * 左摇杆 Y（通道 2）= **小臂** → 电机 2
  * 左摇杆 X（通道 3）= **转台**（半速）→ 电机 3
  * 左旋钮（通道 4）= **推土铲** → 舵机 SM2
  * 右旋钮（通道 5）= **抓斗** → 舵机 SM3

**按键 → 履带**（经舵机口驱动有刷电调，`100`=后退 / `150`=停 / `200`=前进）：

  * 左履带（舵机 SM1）：按键 1（前进）/ 按键 0（后退）
  * 右履带（舵机 SM0）：按键 2（前进）/ 按键 3（后退）

**接收机输出**：电机 `0..3` = 铲斗 / 大臂 / 小臂 / 转台；舵机 `SM0/SM1` = 右 / 左履带（ESC），`SM2/SM3` = 推土铲 / 抓斗。

> 履带的前进 / 后退方向、铲斗 / 抓斗的行程方向都取决于实际接线与安装，若装反了可交换按键或调整脉宽范围。
