RX4MX 叉车（Forklift）演示
===

在 `rx4mx` 上驾驶一台**叉车**：既能像小车一样行驶，又能操作举升臂。控制逻辑全部在接收机上，`tx6ax` 只负责发原始摇杆值。

本课在 `03-Combo`（单摇杆小车：油门 + 转向）的基础上扩展，加入俯仰与举升。摇杆经 `centered()`（见 `00-Default`）还原为带符号值再运算。

**操作**：

  * 左摇杆纵轴（通道 2）= 前进 / 后退（电机 0），受左旋钮（通道 4）限速；按键 1（通道 7）= 行驶刹车。
  * 左摇杆横轴（通道 3）= 举升臂俯仰（电机 2）。
  * 右摇杆纵轴（通道 1）= 举升（电机 1）；按键 2（通道 8）= 举升刹车。
  * 右摇杆横轴（通道 0）+ 右旋钮（通道 5，微调）= 转向舵机 SM0。

**手感**：油门 / 举升 / 俯仰用 `stickToMotor()` 做了**平方响应**——中点附近更细腻，满杆才到全速；举升与俯仰再额外 `/4` 降速，便于精细操作。刹车按键把对应电机设为 `-128`（短接刹车）。
