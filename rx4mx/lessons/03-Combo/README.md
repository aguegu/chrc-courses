RX4MX 单摇杆小车（Combo）
===

本课把一台 RC 小车的**油门与转向合并到一根摇杆**上：右摇杆纵轴给油门、横轴打方向。控制逻辑全在接收机，`tx6ax` 只负责发原始摇杆值。它也是 `04-forklift` 的行驶基础。

**操作**（摇杆经 `centered()` 还原为带符号值，见 `00-Default`）：

  * 右摇杆纵轴（通道 1）= 油门 → 电机 0，受左旋钮（通道 4）限速。
  * 右摇杆横轴（通道 0）= 方向 → 舵机 SM0；右旋钮（通道 5）做方向**微调（trim）**。
  * 按键 0（通道 6）= 刹车（电机设为 `-128`，短接刹车）。

**转向混合**：`steer = -主方向 × 3/4 + 微调 × 1/4`，再映射成舵机脉宽（`150 + steer × 2/5`，即中位 150 附近摆动）。

**限速**：油门 = `摇杆 × speed / 255`，`speed` 取自左旋钮（`0..255`）——旋钮拧到底为满速，拧到 0 则不动，相当于一个总速度上限。
