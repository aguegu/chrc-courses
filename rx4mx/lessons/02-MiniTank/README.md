RX4MX 坦克 / 履带车 演示
===

本课把一辆**双履带（坦克）车**的驱动逻辑放在接收机上：**电机 0 = 左履带**，**电机 1 = 右履带**（`tx6ax` 只负责发原始摇杆值，混控在这里完成）。

两个旋钮：

  * **右旋钮（通道 5）= 模式选择**：拨向一侧用右摇杆开车，拨向另一侧用左摇杆开车，居中则是“坦克模式”。
  * **左旋钮（通道 4）= 速度上限**：整体限速，`0` 到最大。

**三种驾驶模式**（见 `loop()`）：

  1. **右摇杆 arcade**：右摇杆纵轴（通道 1）= 前进 / 后退，横轴（通道 0）= 转向。
  2. **左摇杆 arcade**：左摇杆纵轴（通道 2）+ 横轴（通道 3），同上。
  3. **坦克模式**：左摇杆纵轴（通道 2）直接控制左履带，右摇杆纵轴（通道 1）控制右履带——两根摇杆各管一条履带。

**arcade 混控原理**：把“前进量 Y”和“转向量 X”合成到两条履带上——

```
左履带 = Y - X
右履带 = Y + X
```

直行时 `X = 0`，两侧相等；打杆转向时一侧加、一侧减，实现**差速转向**。合成后可能超过 `127`，所以用 `maxIn3(|左|, |右|, 127)` 归一化，保证满打方向时不削顶、仍按比例输出。

> 因为 `tx6ax` 送来的是原始无符号读数，这里用 `centered()`（见 `00-Default`）把摇杆还原成带符号的 `-127..127`，再做上面的运算。
